# backuper/config.py

**Purpose:** reads the few bootstrap settings that must exist before the database can be opened —
from environment variables / the `.env` file. Everything an operator changes day to day lives in the
database instead and is edited from the bot (see [settings.py](settings.md)).

**Used by:** [cli.py](cli.md) (every command calls `load_config`), [bot/app.py](bot/app.md),
[engine.py](engine.md) (`staging_dir`, `timezone`), [scheduler.py](scheduler.md) (`timezone`).

## `.env` keys

| Key | Meaning |
|---|---|
| `BOT_TOKEN` | Bot token from @BotFather. |
| `API_ID`, `API_HASH` | From my.telegram.org — needed for MTProto (2 GB uploads). Without them the service runs **archive-only**. |
| `OWNER_IDS` | Telegram user IDs that are always admins (comma-separated). |
| `SECRET_KEY` | Fernet key that encrypts every stored secret (generated by `install.sh`). Losing it = re-enter passwords. |
| `TIMEZONE` | Default `Asia/Tehran`; used for schedules and Jalali folder names. |
| `DATA_DIR` | Database, logs, Telegram session, staging (default `./data`). |
| `STAGING_DIR` | Scratch space for zips before archive/upload (default `DATA_DIR/staging`). |
| `TG_PROXY` | Optional proxy for Telegram (`socks5://`, `http://`, `mtproxy://`). |
| `LOG_LEVEL` | `INFO` by default. |

## Classes and functions

| Name | What it does |
|---|---|
| `ConfigError` | Configuration problem with a readable message; `cli.main` prints it and exits with code 2. |
| `AppConfig` | Frozen dataclass with the values above, already parsed (int API_ID, `ZoneInfo`, resolved paths). |
| `AppConfig.env_file` | The `.env` the configuration came from (the [self backup](sources/self_backup.md) includes it). Relative `DATA_DIR`/`STAGING_DIR` are relative to its folder. |
| `AppConfig.db_path` | `DATA_DIR/backuper.db`. |
| `AppConfig.session_path` | `DATA_DIR/telegram` (Telethon adds `.session`). |
| `AppConfig.log_dir` | `DATA_DIR/logs`. |
| `_parse_ids` | Parses `OWNER_IDS` (commas/semicolons) into a set of ints. |
| `load_config` | Loads `.env` (without overriding real environment variables), validates, creates the data/staging/log folders. `require_telegram=False` lets CLI commands and archive-only mode work without Telegram settings. |
